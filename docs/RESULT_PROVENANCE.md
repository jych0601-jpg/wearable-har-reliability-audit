# Result provenance

The numeric files in `results/` were transcribed from the final audited research report
and are intended to expose the manuscript's principal numerical claims in a compact,
human-readable form.

The internal research archive remains the authoritative complete record. It preserved:

- archived V1 predictions and exact recomputation of the primary results,
- 800 core classical-model fits,
- 200 core CNN fits,
- 25 UCI overlap-reduced sensitivity fits,
- calibration and conformal outputs,
- participant-level analysis tables,
- integrity manifests and tests.

The public repository intentionally does not reproduce the internal 23 GB archive.

Before a Zenodo v1.0.0 DOI is issued, exact cleaned scientific source files should be
copied from the archived research package rather than reconstructed from the manuscript.

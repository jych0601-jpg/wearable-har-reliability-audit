# Datasets

This repository does not redistribute raw/source observations.

## UCI HAR

Human Activity Recognition Using Smartphones  
UCI Machine Learning Repository, ID 240  
DOI: https://doi.org/10.24432/C54S4K

The audited study used 10,299 windows, 30 participant IDs, 6 activities, and the
official 561-dimensional transformed feature representation for the classical models.
The dataset uses 2.56-second windows with 50% overlap.

## WISDM

WISDM Smartphone and Smartwatch Activity and Biometrics Dataset  
UCI Machine Learning Repository, ID 507  
DOI: https://doi.org/10.24432/C5HK59

The primary/classical analysis used the official transformed smartwatch-accelerometer
ARFF representation with 50 usable participant files, 18,211 windows, 91 finite numeric
features, and 18 activities.

The secondary CNN used raw smartwatch accelerometer windows. The archived study report
contains 18,380 raw windows; this representation is not row-aligned with the transformed
ARFF representation and is therefore treated as a representation sensitivity.
